CSS Explanation:
This CSS code is used to control the design, layout and appearance of the Woolworths website. It sets the font, colours, spacing and page background. Then it styles the header and navigation. This includes the Woolworths logo, navigation links and hover effects. It also controls headings, paragraphs, buttons the homepage hero section, category cards, promotional sections, product cards, services, contact information and the contact form.

The code uses Flexbox and CSS Grid to arrange content into rows and columns. Effects like :hover and :focus make buttons, cards, links and form fields interactive. It also includes design using @media queries. These queries change the layout for tablets, mobile phones and smaller screens. For example four cards become two on tablets and one on mobile.
